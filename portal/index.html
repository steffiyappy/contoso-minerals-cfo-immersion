Berkas kerja penutupan

ATURAN KERJA

Pastikan setiap kesimpulan dapat ditelusuri

  1. Lampirkan sumber, lalu catat file, lembar, dan ID baris.
  2. Pisahkan mata uang. Tautkan kandidat terkait dengan ID kelompok risiko.
  3. Rekonsiliasi setiap kelompok jurnal sampai dua desimal.
  4. Periksa empat poin kendali sebelum menyimpan draf siap ditinjau.

Gunakan hanya data sintetis dan persona fiktif. Jangan masukkan nama atau informasi pribadi nyata.

Indikator hasil rekonsiliasi

Masukkan jumlah baris unik dari sumber. Pengecualian dapat tumpang tindih. Eksposur adalah potensi risiko, bukan penghematan atau kerugian yang telah dipastikan.

Bukti lokal dan sidik SHA-256

Konten file hanya dibaca di memori untuk menghitung SHA-256. Hanya nama, ukuran, waktu modifikasi, dan hash yang disimpan. Maksimal 50 file, 20 MiB per file. Nama file harus unik.

Pilih satu atau beberapa file bukti

Hash membantu membandingkan file, bukan menjamin kebenaran isinya. Ekspor tidak menyertakan file asli. Hash yang diimpor belum diverifikasi ulang terhadap file asli.

Pengecualian yang dapat ditindaklanjuti

Satu baris per temuan. Kandidat bukan kesimpulan final. Tambahkan hanya baris yang diperlukan, lalu lengkapi sumber dan tindak lanjut.

02 / 04

Jangan jumlahkan nilai antarbaris atau antarkategori. Satu kejadian dapat muncul beberapa kali. ID kelompok risiko opsional menautkan kandidat terkait; tampilan hanya menghitung kelompok unik per mata uang, tanpa menjumlahkan nilai atau mengklaim penghematan.

Usulan penyesuaian, bukan instruksi pembukuan

Gunakan ID jurnal yang sama untuk baris dalam satu jurnal. ID baris harus unik. Setiap ID jurnal dan mata uang harus seimbang hingga dua desimal.

03 / 04

Isi salah satu sisi saja: debit atau kredit. Sisi kosong dihitung sebagai nol. Tidak ada fungsi pembukuan. Usulan hanya untuk ditinjau manusia.

Tinjau satu berkas kerja yang utuh

Pemeriksaan otomatis menguji kelengkapan dan aritmetika, bukan kebenaran akuntansi. Konfirmasi manusia tetap diperlukan.

Empat poin kendali

Centang setelah Anda memeriksa sumber. Perubahan data membatalkan semua konfirmasi dan mengembalikan status menjadi draf.

Status akhir hanya “Siap ditinjau manusia”. Bukan disetujui, dikirim, atau dibukukan.

Pindahkan draf dengan kendali Anda

Ekspor JSON menyertakan payload, versi skema, dan riwayat lokal. Impor file yang sama di peramban lain. Ekspor dapat berisi draf belum lengkap dan selalu diperiksa ulang.

Pilih satu file JSON untuk diperiksa

Maksimal 1 MiB. File diperiksa sebelum diterapkan. Penerapan mengganti satu draf aktif. Ekspor draf saat ini terlebih dahulu jika perlu.

Riwayat lokal

Maksimal 1.000 kejadian terbaru. Riwayat ini dapat diubah bersama file JSON. Ini bukan log audit independen atau tanda persetujuan.

Hal yang perlu diperbaiki

Pilih pesan untuk membuka kolom terkait. Draf belum lengkap tetap dapat disimpan, tetapi tidak dapat ditandai siap ditinjau.
